## Overview

- Assignments contains additional daily practice tasks for CSS, HTML, JavaScript, and React.
- Frontend contains primary learning exercises split by technology and day/topic.
- Resources stores reusable project assets such as images.

## Usage

- Open any HTML file in a browser to view static exercises.
- For React projects, run install and dev commands inside each project folder (for example Frontend/React/1 or Assignments/Frontend/React/Day29).
