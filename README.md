## Description

This repository contains frontend development practice files organized by:

- **Assignments/**: Homework and assignment exercises separated by Backend and Frontend
  - Frontend assignments organized by day with HTML/CSS categories
- **Frontend/**: Main practice files for frontend development
  - HTML files organized by day covering various concepts (forms, tables, lists, iframes)
  - CSS files for styling
- **Resources/**: Project resources including images and other assets

## Usage

Open any HTML file in a web browser to view the content. CSS files are located in `Frontend/CSS/` for styling.
