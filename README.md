## Description

This repository contains HTML practice files organized by day. Each day folder includes HTML files for learning and practicing various HTML concepts including forms, tables, lists, and iframes. The Assignments folder contains homework exercises.

## Usage

Open any `index.html` file in a web browser to view the content.
